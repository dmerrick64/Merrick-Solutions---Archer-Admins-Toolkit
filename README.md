### **Merrick Solutions - Archer Admin Toolkit**

A free and open-source toolkit for Archer administrators and developers.



**The project includes:**



Archer package releases

Full source code

Build documentation

AI-assisted development instructions



The goal is to help the Archer community build, extend, and maintain solutions independently.



**Downloads:**

Archer Package (.zip)

Source Distribution (.zip)

AI Builder Package (.zip)
