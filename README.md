### **Merrick Solutions - Archer Admin Toolkit**

A free and open-source toolkit for Archer administrators and developers. 
This is a hobby project for me to help me learn AI as well as create all those tools I wished I had.
The goal is to help the Archer community build, extend, and maintain solutions independently. Also use it as a starting point to roll your own.



**The project includes:**

Archer package releases

Full source code

Build documentation

AI-assisted development instructions



**Downloads:**

Archer Packages (.zip)

Source Distribution (.zip)

AI Builder Package (.zip)
